# 海音ちゃんの冒険２ — 独立した冒頭テスト

前作 ROCKSIDE v0.12.0 を複製した続編開発用プロジェクト。由来のコミットは BASE_ORIGIN.json。前作リポジトリへの書き込みは行わない。

- src/: 前作から継承したゲームコード。変更はここで行う。
- src/02c_sequel.js: 新しい海音ちゃんの素材表示・サイズ比較。
- assets/: 前作素材と開発用メタデータ。
- dist/: 公開用ファイル。
- dist/first-test/: 最初の独立した訓練場を保存。

ビルド: `python3 tools/build.py --out dist/index.html`

この版のステージ・ボス・物語は前作由来の確認用コンテンツ。続編固有の短い冒頭（目覚め・右腕への驚き・部屋と廊下の操作練習）を実装。旧ステージは継承コードとして保持。進行データは rockside2_progress_v1 を使用する。

新モデルの40px/48pxは描画セルの寸法。身体の当たり判定と移動設定は比較用に前作と同じ。8ポーズのため走り射撃・被弾は仮表示。元JPEGは保持し、背景の白を読み込み時に除去する仮素材。実装用の完成透過スプライトへ後日交換する。

冒頭: タイトルから開始。Enter・画面タップ・SHOTで会話送り。右上SKIPまたはEscで会話省略。探索中Escでタイトルへ。廊下の出口でテスト終了し、タップでタイトルへ戻る。寝姿・座り姿と表情PNGは試作用素材。ベッド・室内は既存のCanvas方式で描画。

続編の開始地点は屋敷の中。前作で和解したポルターガイストの子の呼称は「カナタちゃん」（リネ）で統一する。背景の床・壁・窓・家具は共通のドット粒度で整備予定。
